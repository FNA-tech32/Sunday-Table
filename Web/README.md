# ☕ Sunday Table — Web Application

Aplicación web desarrollada con **Astro 5**, **CSS3** y **JavaScript Vanilla**.

## 🚀 Comandos

Todos los comandos se ejecutan desde el directorio `Web/`:

| Comando | Acción |
| :--- | :--- |
| `npm install` | Instala las dependencias del proyecto |
| `npm run dev` | Inicia el servidor de desarrollo local en `localhost:4321` |
| `npm run build` | Compila el sitio estático optimizado en `./dist/` |
| `npm run preview` | Previsualiza la versión de producción localmente |

## 📁 Rutas de la Web

- `/` — Página principal de Sunday Table (Hero, Intro, Pilares)
- `/menu` — Menú de productos y especialidades interactivas
- `/historia` — Historia y testimonios de clientes
- `/contacto` — Ubicaciones, teléfonos, email de contacto y horarios (incluye brunch dominical)

Para más detalles sobre la arquitectura y la marca, consulta el [README principal](../README.md).
